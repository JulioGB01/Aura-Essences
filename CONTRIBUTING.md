# Guía de contribución

Gracias por ayudar a mejorar Aura Essences. Las contribuciones deben mantener el proyecto útil para una tienda pública, segura y fácil de operar.

## Antes de abrir un issue o pull request

- Busca si el tema ya fue reportado.
- Explica el problema, el navegador y los pasos para reproducirlo.
- Mantén los cambios pequeños y enfocados.
- Actualiza la documentación si el comportamiento visible cambia.

## Datos que no deben publicarse

No incluyas contraseñas, tokens, datos de clientes, costos, proveedores, conversaciones privadas, enlaces de administración ni inventario interno. Usa únicamente imágenes y textos con permiso de uso.

Los endpoints públicos deben exponer solo información comercial que un comprador pueda ver.
